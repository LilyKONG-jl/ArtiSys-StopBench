# ArtiSys-StopBench
ArtiSys-StopBench: A SysOntology-Grounded Benchmark for Task-Critical Stop Decisions in LLM-Based Engineering Artifact Ontology Extraction
ArtiSys-StopBench includes 350 engineering artifacts across seven categories, 10,500 diagnostic questions, and 33,600 task instances covering evidence-conditioned extraction, diagnostic question answering, and state- or trajectory-based stop decisions. Each artifact is linked to evidence spans, extraction states, critical states, minimal working systems, stop annotations, and stop-signal vectors. 
**ArtiSys-StopBench evidence-backed generation pipeline.** The benchmark construction starts from a fixed 350-artifact registry and local Wikipedia archive, extracts v0.5 source spans, builds v0.6 ontology/mechanism/question assets, and packages them as the v0.61 real Wikipedia evidence candidate package. The v3.0 question engine consumes this evidence package and is progressively repaired through v4.1, where the Diagnostic QA task is frozen as Task 1 with 21,000 bilingual questions and no stop-decision fields. The v5.0 StopBench layer then adds a shared gold bridge, Task 0 evidence-conditioned extraction, and Task 2 trajectory stop-decision tasks, with public/private separation and quality-gate validation.
